# Datos de demostración

Estos recursos son pequeños y deliberadamente ilustrativos. Sirven para las pruebas locales de inferencia, mapeo temporal/geográfico y API de lotes; no representan mediciones verificadas.

- `air-quality-bogota.csv`: columnas tabulares con dos estaciones, timestamps y coordenadas.
- `noise-batch.json`: contrato de `records:batch` con campos acústicos variables.

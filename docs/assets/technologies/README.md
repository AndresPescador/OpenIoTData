# Iconos de tecnologías

Los SVG de esta carpeta se obtuvieron de [Simple Icons](https://github.com/simple-icons/simple-icons)
en el commit `8a040dd8e1f7d99d27827efd4089a5434fdb7b5c` de `develop` (consulta: 1 de
septiembre de 2026). Se conservaron las formas de los iconos y se añadió únicamente un
fondo neutro para que sean legibles en los temas claro y oscuro de GitHub.

Simple Icons se distribuye bajo CC0-1.0, pero la licencia de cada marca puede variar y
los nombres/logotipos siguen siendo marcas de sus titulares. Este proyecto usa los
iconos sólo para identificar las tecnologías utilizadas. Revisa las directrices de cada
marca antes de reutilizar estos assets fuera de este repositorio.

|---|---|---|
| `nextdotjs.svg` | Next.js | [Vercel Brand](https://vercel.com/design/brands#next-js) |
| `fastapi.svg` | FastAPI | [FastAPI](https://github.com/tiangolo/fastapi) |
| `keycloak.svg` | Keycloak | [Keycloak](https://www.keycloak.org/) |
| `postgresql.svg` | PostgreSQL / PostGIS | [PostgreSQL](https://wiki.postgresql.org/wiki/Logo) · [trademarks](https://www.postgresql.org/about/policies/trademarks/) |
| `redis.svg` | Redis | [Redis brand guidelines](https://redis.io/brand-guidelines) |
| `celery.svg` | Celery | [Celery](https://github.com/celery/celery) |
